1. Mengubah Domain / URL API Backend

Aplikasi ini terhubung ke Laravel backend melalui REST API. Domain harus diubah di 2 file:

1 File utama — konfigurasi API
File: lib/config/api_config.dart
class ApiConfig {
  // GANTI baris di bawah ini dengan domain Anda sendiri:
  static const String baseUrl = 'https://YOUR-DOMAIN.com/api/v1';
  //                              ^^^^^^^^^^^^^^^^^^^^^^^^
  // Contoh: 'https://posretail.whitelabel.co.id/api/v1'
  //         'https://api.tokokita.com/api/v1'

  static const Duration connectTimeout = Duration(seconds: 15);
  static const Duration receiveTimeout = Duration(seconds: 15);
}

File ini adalah sumber utama — semua API call di aplikasi (login, produk, order, dll) membaca ApiConfig.baseUrl dari sini.

2 File tampilan — halaman Settings
File: lib/screens/settings/settings_screen.dart
import '../../config/api_config.dart';    <!-- PASTIKAN import ini ada

class _SettingsScreenState extends State<SettingsScreen> {
  String _apiUrl = ApiConfig.baseUrl;    <!-- PASTIKAN pakai ApiConfig
  ...

Halaman Settings menampilkan URL API yang sedang aktif dan sudah membaca dari ApiConfig.baseUrl. Jika import api_config.dart tidak ada, tambahkan.

Tips:
  • Gunakan https:// (bukan http) untuk production
  • Pastikan Laravel backend sudah di-deploy dan endpoint /api/v1/login berfungsi
  • Untuk development di emulator Android, gunakan http://10.0.2.2:8765/api/v1
  • Untuk development di HP fisik, gunakan IP lokal laptop: http://192.168.x.x:8765/api/v1

2. Setup Laravel Backend

Aplikasi Flutter POS Retail membutuhkan Laravel backend yang berjalan di domain yang sama dengan baseUrl di atas. Backend ini menyediakan REST API untuk login, produk, order, customer, dan payment gateway.

1 Clone / pindahkan project Laravel

Project Laravel backend berada di folder terpisah. Pindahkan ke server atau jalankan secara lokal:

# Masuk ke folder Laravel backend
cd D:\project laravel\pos-retail

# Copy .env.example ke .env (jika belum ada)
copy .env.example .env

# Install dependencies
composer install

# Generate APP_KEY
php artisan key:generate

# Setup database di .env (DB_DATABASE, DB_USERNAME, DB_PASSWORD)
# Lalu migrate + seed
php artisan migrate --seed

# Jalankan development server (port 8765)
php artisan serve --host=127.0.0.1 --port=8765
2 Konfigurasi CORS (wajib!)

Agar Flutter app bisa akses API dari domain berbeda, Laravel harus mengizinkan CORS.

File: config/cors.php (Laravel 11) atau bootstrap/app.php
// Laravel 11 — di bootstrap/app.php, tambahkan middleware CORS
->withMiddleware(function (Middleware $middleware) {
    $middleware->api(prepend: [
        \Illuminate\Http\Middleware\HandleCors::class,
    ]);
})

// Lalu di config/cors.php:
return [
    'paths' => ['api/*', 'sanctum/csrf-cookie'],
    'allowed_methods' => ['*'],
    'allowed_origins' => ['*'],               // ganti dengan domain Flutter nanti
    'allowed_headers' => ['*'],
    'exposed_headers' => [],
    'max_age' => 0,
    'supports_credentials' => false,
];
3 Setup Sanctum (API Token Auth)
File: routes/api.php
Route::prefix('v1')->group(function () {
    Route::post('/login', [AuthController::class, 'login']);  // tanpa auth

    Route::middleware('auth:sanctum')->group(function () {
        Route::get('/user', [AuthController::class, 'user']);
        Route::post('/logout', [AuthController::class, 'logout']);
        Route::get('/products', [ProductController::class, 'index']);
        Route::post('/orders', [OrderController::class, 'store']);
        Route::get('/customers', [CustomerController::class, 'index']);
        // ... dan lainnya
    });
});
4 Deploy ke Server / Domain

Untuk production, deploy Laravel ke web server (Nginx/Apache) yang melayani domain Anda:

# Contoh Nginx config
server {
    listen 80;
    server_name posretail.whitelabel.co.id;

    root /var/www/pos-retail/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}
Cek koneksi: Setelah backend online, test API login dari browser atau terminal:

curl -X POST https://YOUR-DOMAIN.com/api/v1/login -H "Content-Type: application/json" -d '{"email":"admin@test.com","password":"password"}'

Jika return JSON dengan token, backend sudah siap. Jika return 404 atau error lain, cek konfigurasi web server dan .env (APP_URL harus sesuai domain).
Database yang perlu di-seed:
  • Tabel users — akun login (admin, kasir, manager)
  • Tabel products — daftar produk beserta barcode, harga, stok
  • Tabel categories — kategori produk
  • Tabel customers — data pelanggan (opsional)
  • Tabel payment_methods — metode pembayaran (cash, QRIS, transfer)
  • Tabel tables — meja resto (jika pakai fitur meja)
  • Tabel personal_access_tokens — token Sanctum (auto-migrate)

3. Mengubah Icon Aplikasi

Icon aplikasi adalah gambar yang muncul di home screen HP. Cara termudah adalah menggunakan package flutter_launcher_icons.

Langkah 1 — Tambahkan dependency

File: pubspec.yaml (bagian dev_dependencies)
dev_dependencies:
  flutter_test:
    sdk: flutter
  flutter_lints: ^6.0.0
  flutter_launcher_icons: ^0.14.3     <!-- TAMBAHKAN baris ini -->

Langkah 2 — Tambahkan konfigurasi icon

File: pubspec.yaml (di bagian bawah, SEJAJAR dengan flutter:)
flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/icon/app-icon.png"      <!-- path ke icon Anda -->
  adaptive_icon_background: "#FFFFFF"          <!-- warna background (opsional) -->
  adaptive_icon_foreground: "assets/icon/app-icon.png"

Langkah 3 — Siapkan file icon

Buat folder assets/icon/ dan letakkan file PNG icon Anda di sana. Ukuran minimum: 1024x1024 px (tanpa background, transparan).

Langkah 4 — Generate icon

flutter pub get
flutter pub run flutter_launcher_icons

Command ini otomatis generate semua ukuran icon untuk Android (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi) dan iOS (semua AppIcon.appiconset).

Alternatif manual (tanpa package):
Icon Android ada di android/app/src/main/res/mipmap-*/ic_launcher.png — ganti semua 5 file PNG tersebut dengan icon Anda (ukuran: 48, 72, 96, 144, 192 px).

Icon iOS ada di ios/Runner/Assets.xcassets/AppIcon.appiconset/ — ganti semua file PNG sesuai ukuran yang terdaftar di Contents.json.

4. Mengubah Package Name / Bundle ID

Package name adalah identitas unik aplikasi di Play Store / App Store. Format: com.namaperusahaan.namaaplikasi. Wajib diganti sebelum rilis.

Android: applicationId

File: android/app/build.gradle.kts
defaultConfig {
    applicationId = "com.tokokita.pos_app"    <!-- GANTI di sini -->
    ...
}

Juga update namespace di file yang sama (baris 9): 

android {
    namespace = "com.tokokita.pos_app"          <!-- GANTI di sini -->
    ...
}

Dan update folder struktur MainActivity.kt sesuai package name baru: 

android/app/src/main/kotlin/com/tokokita/pos_app/MainActivity.kt
                                         ^^^^^^^^^^^^^^^^^^^^
                                         sesuaikan dengan applicationId

iOS: Bundle Identifier

File: ios/Runner.xcodeproj/project.pbxproj

Cari PRODUCT_BUNDLE_IDENTIFIER (ada 3 tempat: Debug, Release, Profile) dan ganti nilainya. Atau lebih mudah: buka di Xcode → Runner target → General → Bundle Identifier.

Aturan penamaan package:
  • Harus lowercase (huruf kecil semua)
  • Dibatasi dengan titik: com.nama.namaapp
  • Tidak boleh pakai angka di depan
  • Harus unik — tidak boleh sama dengan app lain di Play Store

5. Mengubah Warna Tema

Aplikasi ini menggunakan Material 3 dengan colorSchemeSeed. Cukup ganti satu warna, seluruh tema otomatis menyesuaikan (light + dark).

File: lib/main.dart
MaterialApp(
  title: 'POS Retail',
  debugShowCheckedModeBanner: false,
  theme: ThemeData(
    colorSchemeSeed: const Color(0xFF4F46E5),  <!-- GANTI warna di sini -->
    useMaterial3: true,
    brightness: Brightness.light,
  ),
  darkTheme: ThemeData(
    colorSchemeSeed: const Color(0xFF4F46E5),  <!-- GANTI warna di sini -->
    useMaterial3: true,
    brightness: Brightness.dark,
  ),
  ...
)

6. Mengubah Splash Screen

Splash screen adalah tampilan yang muncul sebelum aplikasi terbuka penuh.

Android: Warna Background Splash

File: android/app/src/main/res/values/styles.xml
<?xml version="1.0" encoding="utf-8"?>
<resources>
    <style name="LaunchTheme" parent="@android:style/Theme.Light.NoTitleBar">
        <item name="android:windowBackground">@drawable/launch_background</item>
    </style>
</resources>
File: android/app/src/main/res/drawable/launch_background.xml
<?xml version="1.0" encoding="utf-8"?>
<layer-list xmlns:android="http://schemas.android.com/apk/res/android">
    <item android:drawable="@android:color/white" />   <!-- GANTI warna background -->
</layer-list>

iOS: Launch Screen

File: ios/Runner/Base.lproj/LaunchScreen.storyboard

Buka di Xcode untuk edit visual, atau edit langsung XML-nya untuk mengubah warna background dan gambar.

Custom Splash Screen (dalam Flutter)

Splash screen di Flutter ada di lib/main.dart pada class SplashScreen. Anda bisa ganti icon dan teks: 

class SplashScreen extends StatefulWidget {
  ...
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            // GANTI icon di bawah:
            Icon(Icons.store, size: 80, color: Theme.of(context).colorScheme.primary),
            //              ^^^^^^^^
            // Alternatif: Image.asset('assets/logo.png', width: 120),
            
            const SizedBox(height: 16),
            // GANTI teks di bawah:
            const Text('POS Retail', style: TextStyle(fontSize: 24, fontWeight: FontWeight.w800)),
            //           ^^^^^^^^^^^
            const SizedBox(height: 24),
            const CircularProgressIndicator(),
          ],
        ),
      ),
    );
  }
}

7. Mengubah Versi Aplikasi

File: pubspec.yaml (baris 19)
version: 1.0.0+1
#         ^^^^^ ^^
#         |     └─ build number (integer, auto-increment tiap upload ke store)
#         └─────── version name (major.minor.patch)

Contoh: version: 2.1.0+5 artinya versi 2.1.0, build ke-5.

PENTING: Build number HARUS selalu naik (tidak boleh turun/reset) saat upload ke Google Play Store dan Apple App Store. Jika tidak, upload akan ditolak.

8. Ringkasan File yang Perlu Diedit

Yang Diubah File Yang Diedit
Domain API lib/config/api_config.dart baseUrl
Nama App (Android) android/app/src/main/AndroidManifest.xml android:label
Nama App (iOS) ios/Runner/Info.plist CFBundleDisplayName + CFBundleName
Nama App (Flutter) lib/main.dart title + teks SplashScreen
Icon Aplikasi pubspec.yaml + assets/icon/ Konfigurasi flutter_launcher_icons
Package Name (Android) android/app/build.gradle.kts applicationId + namespace
Package Name (iOS) ios/Runner.xcodeproj/project.pbxproj PRODUCT_BUNDLE_IDENTIFIER
Warna Tema lib/main.dart colorSchemeSeed
Splash Background android/.../launch_background.xml android:drawable warna
Splash Flutter lib/main.dart Class SplashScreen
Versi pubspec.yaml version: x.y.z+build

Build APK / App Bundle

Setelah semua perubahan selesai, build aplikasi:

# Build APK (untuk testing / distribusi langsung)
flutter build apk --release

# Build App Bundle (untuk upload ke Google Play Store)
flutter build appbundle --release

# Build iOS (harus dari macOS + Xcode)
flutter build ios --release

Output APK: build/app/outputs/flutter-apk/app-release.apk
Output AAB: build/app/outputs/bundle/release/app-release.aab
